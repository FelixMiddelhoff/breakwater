# BW021: AlterDatabase affects the whole database

`migrationBuilder.AlterDatabase()` (collation, edition, and other database-wide
settings) affects every table and every other application sharing the database,
not just the one running the migration.

## Why it hurts

A database-level change can require no other connections be active, and its effect
is not scoped to this application: every table, and every other application
sharing the database, is affected.

## Example

```csharp
protected override void Up(MigrationBuilder migrationBuilder)
{
    // breakwater: expect BW021
    migrationBuilder.AlterDatabase();
}
```

## Safe alternative

Run database-wide changes as a deliberate, scheduled operation outside normal
deploys, coordinated with everyone sharing the database - not as a side effect of
an application migration.

## When it is fine

This is a Suggestion-tier rule (`Info` severity, IDE hint only, no build output) by
default. Raise it if you want it to fail the build:

```ini
dotnet_diagnostic.BW021.severity = warning
```

## Not reported

Nothing special: any call to `AlterDatabase()` is reported.
