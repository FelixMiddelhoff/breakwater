# Security

Breakwater runs inside the compiler as an analyzer and only reads source code.
It does not open network connections or touch files.

If you find a vulnerability (for example an input that makes the analyzer
execute code or hang the compiler), please report it privately through
[GitHub security advisories](https://github.com/FelixMiddelhoff/breakwater/security/advisories/new)
instead of a public issue. Expect a first answer within a week.

Supported versions: the latest release.
